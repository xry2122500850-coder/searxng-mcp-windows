## 🛠️ Tools Reference

| Tool | Description | Use Case |
|------|-------------|----------|
| `web_search` | General web search | Finding information |
| `image_search` | Image search | Finding images, logos |
| `news_search` | News articles | Current events |
| `video_search` | Video search | Tutorials, talks |
| `technical_search` | Code/docs search | Programming help |
| `search_suggestions` | Autocomplete | Query refinement |
| `fetch_url` | Content extraction | Reading articles |
